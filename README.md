# ONG Esperança

Projeto de estudo desenvolvido para praticar HTML5 e CSS3.

## Sobre o projeto

Site institucional fictício para uma ONG, desenvolvido com três páginas:
- Página inicial
- Projetos
- Cadastro

## Tecnologias

- HTML5
- CSS3

## Funcionalidades

- Navegação entre páginas
- Formulário com validação HTML5
- Efeitos de hover e focus
- Transições e animações
- Organização de imagens em pasta própria
